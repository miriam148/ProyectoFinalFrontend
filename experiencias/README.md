🌎 Frontend - Proyecto Final: Experiencias de Viaje

Este proyecto es el frontend de una aplicación donde los usuarios pueden registrarse, iniciar sesión y subir sus experiencias de viaje con imágenes.Se conecta al backend desarrollado en Node.js y MongoDB.

🛠️ Tecnologías utilizadas

React 19

React Router DOM 7

Vite

Context API

CSS (con Mobile First)

Fetch para peticiones al backend

📁 Estructura principal del frontend

/components → Componentes principales (crear experiencia, editar, detalle, contacto, etc.)

/pages → Páginas principales (Landing, Login, Registro, Home, Experiencias, Perfil)

/context → Contexto de autenticación (AuthContext)

/style → Archivos CSS organizados por página o componente

🔧 Instalación y uso

Clona el repositorio:

git clone https://github.com/miriam148/ProyectoFinalFrontend.git

Accede a la carpeta:

cd ProyectoFinalFrontend

Instala las dependencias:

npm install

Inicia el proyecto en modo desarrollo:

npm run dev

La aplicación se abrirá en:

http://localhost:5173

🌟 Funcionalidades principales del frontend

Registro e inicio de sesión de usuarios

Visualización de experiencias de viaje

Crear nueva experiencia con imagen

Editar texto de la experiencia

Cambiar imagen de experiencia (desde un componente específico)

Ver perfil de usuario y editar datos

Subir o cambiar imagen de perfil

Navegación protegida según autenticación

Diseño responsivo (mobile first)
